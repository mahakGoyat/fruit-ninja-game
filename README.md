# 🍉 Fruit Ninja Game

> A neon-styled fruit-slasher game built with TypeScript — swipe, slice, score. Built in Google AI Studio.

![TypeScript](https://img.shields.io/badge/TypeScript-3178C6?style=for-the-badge&logo=typescript&logoColor=white)
![Vite](https://img.shields.io/badge/Vite-646CFF?style=for-the-badge&logo=vite&logoColor=white)

---

## ✨ What it does

A browser-based arcade game — slice fruits as they fly across the screen, avoid bombs, chase a high score.

| Feature | Details |
|---|---|
| **Slicing mechanic** | Mouse/touch swipe detection slices fruit sprites in real time |
| **Scoring** | Points per fruit sliced, combo bonuses |
| **Neon visuals** | Glowing fruit trails and background effects |

## 🛠️ How it's built

- **Core** — TypeScript, built and bundled with Vite
- **Rendering** — Canvas-based sprite animation
- Built originally in **Google AI Studio**, pushed to GitHub via its Integrations tab

## 📁 Project structure

```
.
├── src/                 # game logic and rendering
├── public/              # static assets (sprites, sounds)
├── index.html
├── package.json
└── vite.config.ts
```

## 🚀 Run it locally

```
git clone https://github.com/mahakGoyat/fruit-ninja-game.git
cd fruit-ninja-game
npm install
npm run dev
```
